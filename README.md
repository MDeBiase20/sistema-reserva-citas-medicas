# Sistema de Reserva de Citas Médicas

Sistema web para la gestión y reserva de citas médicas, desarrollado con **PHP, Laravel, MySQL y AdminLTE**.

El proyecto permite administrar información relacionada con la gestión de citas mediante una aplicación web basada en Laravel.

## 🚀 Características

* Gestión de citas médicas.
* Registro y administración de información relacionada con las citas.
* Gestión de datos mediante formularios.
* Persistencia de información en MySQL.
* Interfaz administrativa basada en AdminLTE.
* Arquitectura MVC.
* Uso de Eloquent ORM.
* Migraciones y seeders de Laravel.
* Sistema web adaptable a diferentes resoluciones.

## 🏗️ Arquitectura

La aplicación utiliza la arquitectura MVC de Laravel:

```text
app/
├── Http/
│   ├── Controllers/
│   └── Requests/
│
├── Models/
│
database/
├── migrations/
└── seeders/

resources/
├── views/
└── ...

routes/
└── web.php
```
